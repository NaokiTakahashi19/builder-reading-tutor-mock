# BUILDER 英語AIチュータ・読解モック

長文・対話文の小問に対し、場面や根拠を生徒自身が考える学習支援のプロトタイプです。

## 試す

[ブラウザでモックを開く](https://naokitakahashi19.github.io/builder-reading-tutor-mock/)

`index.html` をダウンロードしてブラウザで開いても動きます。ビルドやサーバーは不要です。

1. ページ「p.5」、大問「1」、小問「（1）〜（5）」を選びます。
2. 選択問題は設問の選択肢を押すと、選んだ答えに応じたコメントが表示されます。
3. 「先生と一緒に考える」で、小問の種類に応じて場面・気持ち、または本文の根拠を選びます。
4. 選んだ根拠へのフィードバックを受け、必要な文を選び直したり追加したりします。
5. ヒントの問いかけに合わせ、必要な語句が強調されます。
6. 記述問題の「ノートの答えを確認」では、ノート撮影 → 読み取り結果 → アドバイスの流れを体験できます。

設問と選択肢は画面上部に固定され、対話文だけをスクロールできます。

## 実装状況

- 小問5問の対話・フィードバックを固定データで再現しています。
- AIによる対話、実際の撮影、OCRは未接続です。
- 撮影画面はノートのサンプル画像を表示し、撮影ボタンで対応する固定の読み取り結果を表示します。
- 答えの修正も試せます。入力内容はサーバーへ送信しません。
